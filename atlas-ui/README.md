# Atlas UI

A minimal vanilla-JS app shell built with Vite. Dark "observatory" theme.

Two routes — **Dashboard** (empty) and **Settings** — with a sidebar navigator, logo, and topbar title.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/
```

Everything lives in `index.html`, `src/renderer.js`, and `src/styles.css`.
